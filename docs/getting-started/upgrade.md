## Upgrade guide

Breaking changes and version notes are tracked in the repository **[CHANGELOG](https://github.com/lara-zeus/chaos/blob/3.x/CHANGELOG.md)**.

When upgrading across major Filament or Chaos versions, compare that file and your resource `form` / `table` / `infolist` signatures (Filament v5 uses **`Schema`** for several builders that previously used **`Form`**).
